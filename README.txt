ILLUSIONARY キャラクター017〜030 追加ファイル

内容:
- character-017.html 〜 character-030.html（詳細ページ14枚、プロンプトとコピー機能付き）
- characters-17-30.json（一覧用JSONの追加データ）
- README.txt

設置方法:
1. HTMLファイル14枚を、既存の index.html と同じ階層（リポジトリ直下）へアップロードしてください。
2. characters-17-30.json を開き、14件のオブジェクトを既存の characters.json 配列の末尾へ追加してください。
   注意: characters-17-30.json は追加分だけです。既存の characters.json 全体をこのファイルで置き換えないでください。
3. 画像は生成・同梱していません。画像を表示する場合は、各キャラクター画像を images/character-017.jpg 〜 images/character-030.jpg の名前で配置してください。
4. 既存の style.css と index.html を使用します。既存ファイルはこのZIP内に含めておらず、変更もしません。

各JSON項目の page は character-NNN.html、image は images/character-NNN.jpg を参照します。
一覧に表示するには、追加JSONデータを既存 characters.json に統合してください。
